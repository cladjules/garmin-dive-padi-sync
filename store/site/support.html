Support

Connect Garmin

  1. Sync the watch with Garmin Dive or Garmin Connect on the phone.
  2. Open DiveBridge from the Chrome toolbar.
  3. Use the official Garmin link to create a revocable Personal API key.
  4. Paste the key into DiveBridge and select Connect Garmin.

Import into PADI

  1. Sign in at learning.padi.com/logbook.
  2. Select Import Garmin dives.
  3. Choose dives, review the fields, and confirm.

Troubleshooting

  • If no dives appear, finish the phone sync and use Check for Garmin dives.
  • If a dive is skipped, check for a PADI log on the same date.
  • If Garmin rejects the key, create a new key and choose Replace key.
  • If PADI changes unexpectedly, reload the logbook before retrying.
